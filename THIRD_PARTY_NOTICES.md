# 3D Wave Grid

The instanced cube grid and Gaussian-envelope ripple shader in `src/lib/wave-grid.ts` are adapted from **3D Wave Grid** by franky-adl. Source supplied by the site owner: https://github.com/HaningZS/3d-wave-grid. Visual reference: https://projects.arkon.digital/threejs/wavy-cubes/.

The integration uses a bounded uniform ripple buffer, reduced rendering resolution, offscreen suspension, and React-managed cleanup in place of the original debug interface and global orchestrator.
